# Student Loan Eligibility & Risk-Screening Tool

A rule-based tool that helps bank credit analysts assess whether an international
student is eligible for a student loan in France where two scenario created-
1. A standard loan
2. A micro-credit loan

The tool checks applicant information against predefined eligibility rules,
identifies missing documents or risk factors, and returns one of three decisions:

- Eligible
- Conditionally eligible
- Not eligible

## Problem

International students in France may face difficulty obtaining student loans because
banks often require a French-resident guarantor and apply strict eligibility criteria.

This project creates a simple decision-support workflow for bank staff to assess
student-loan applications consistently.

## Scope

This is Version 1 of the project:

- Synthetic student-loan application data
- PostgreSQL database design
- Python rule-based eligibility engine
- Decision output: Eligible / Conditional / Not eligible
- SQL analysis of approval patterns and rejection reasons

This is not a production credit-scoring model and does not make final lending decisions.

## Scenario Comparison Results

I compared two loan-product configurations using the same 150 synthetic student
applications and eligibility-screening approach.
```
| Decision | Standard student loan | Short-term micro-loan |
|---|---:|---:|
| Eligible | 0 (0.0%) | 12 (8.0%) |
| Conditional | 5 (3.3%) | 123 (82.0%) |
| Not eligible | 145 (96.7%) | 15 (10.0%) |
| **Total applications** | **150** | **150** |
```
### Interpretation

In this synthetic test, the short-term micro-loan scenario produced fewer
“Not eligible” outcomes than the standard student-loan scenario. The standard
scenario classified 96.7% of applications as “Not eligible”; the micro-loan
scenario classified 10.0% as “Not eligible” and 82.0% as “Conditional.”

This suggests that the shorter loan term and lower maximum loan amount changed
how the defined eligibility rules classified applications. Many micro-loan
applications were still marked “Conditional,” meaning they would require
additional information or human review in this prototype.

### Important limitation

The dataset is synthetic, and these outcomes are generated by predefined rules.
They do not represent actual bank decisions, establish that a micro-loan is safer,
or estimate a real probability of default. The results demonstrate how changing
product parameters can affect rule-based eligibility outcomes in a prototype.
